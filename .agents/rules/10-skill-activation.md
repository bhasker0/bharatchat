# Skill Activation Rule: The 1% Rule

## Mandatory Activation Threshold
If there is even a 1% chance an available skill applies to what you are doing, you ABSOLUTELY MUST read the skill.
This is not negotiable. This is not optional. You cannot rationalize your way out of this.

## Red-Flag Thoughts to Reject
- "This is just a simple question"
- "I remember what this skill says"
- "This seems like overkill"
- "I need more context first"

When these rationalizing thoughts occur, stop and identify which skill or skills apply to the current situation — then you MUST use them.

## Subagent Delegation
The 1% rule does not survive delegation unless the brief carries it explicitly.
When dispatching any subagent:
1. Check the available skill list first.
2. If a skill fits the delegated task, phrase the instruction as: `Use the <exact skill name> skill to <task>.`
3. Ask the subagent to report the skills it loaded in its response.
