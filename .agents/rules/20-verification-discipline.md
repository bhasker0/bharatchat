# Verification Discipline Rule: Evidence-Based Proof

## Core Imperative
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE.
Skipping any verification step is misrepresentation, not efficiency.

## 5-Step Verification Protocol
Before asserting that any task, fix, or implementation is complete:
1. **Identify** — What exact command or test proves this claim?
2. **Execute** — Run it fresh (not from memory or earlier steps).
3. **Examine** — Read complete output, logs, and exit status.
4. **Confirm** — Do the results actually support the claim? Are there side effects or regression errors?
5. **State** — Make the claim with cited evidence.
