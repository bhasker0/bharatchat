# Communication & Writing Style Rule

## Direct & High-Signal Communication
- **No AI Slop**: Avoid sycophancy, repetitive conversational fillers ("Certainly!", "I would be happy to help with that!"), and inflated claims.
- **Concise & Factual**: Answer technical questions directly with code, command outputs, or verified facts.
- **Clickable References**: Format code symbols and file references using clickable GitHub markdown file links (`file:///path/to/file#L1-L10`).
- **Structured Highlights**: Use standard GitHub alert callouts (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`) to elevate critical context.
